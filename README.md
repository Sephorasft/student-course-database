# student-course-database
a database project that models students, courses, teachers, and locations using an entity relationship diagram and a conceptual data model.
## Main entities
-Student
-Courses
-Teacher
-Location
-Stde course
## Relationships
-A teacher can teach many courses but a course can be teach by only one teacher.
-A student can enroll in many courses and a course can contains many students.
-A location can be associated with many students, but a student can only have one location.
